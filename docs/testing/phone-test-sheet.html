Cricket Replay: quick phone check

About 20–30 minutes. Use one iPhone and one OnePlus. Tick the results below. Write a note only if something goes wrong. No reports or technical numbers to copy.

The app owner should install the latest app first. Keep the recording phone sideways and the app on screen. Enable auto-rotate on OnePlus; turn off Portrait Orientation Lock on iPhone. Leave the recording settings at 120 / 20.

1. Camera and recent clip — do this on each phone

  1. Turn Wi-Fi off before opening the app. Point the rear camera at something with readable words and move your hand beside it.
  2. Tap Start rear camera. Allow Camera if asked. The live view should be upright, words should read normally, and movement should look natural.
  3. Wait 25 seconds. Tap Extract latest review clip, wait for “ready”, then Play recording clip. You should see roughly the last 20 seconds, without obvious freezing or jumps. No sound is expected.
  4. Close playback. The live view should return and recording should still be running. Tap Stop recording.
  5. Turn the phone to the other sideways direction, start again, and check that the live picture is still upright and readable. Stop when done. Repeat steps 1–4 if the recorded clip looked wrong.

2. Send real camera reviews — three times in each direction

Turn mobile data off on both phones. Join a phone hotspot or local Wi-Fi that works without internet. Pair before starting the camera. Keep footage on these phones.

  1. On iPhone choose Host, then Start host & show QR. On OnePlus choose Camera, then Scan host QR & connect. Allow Local Network access if asked.
  2. Hold Camera sideways, tap Start rear camera and wait 25 seconds. Aim at your hand or a moving object.
  3. On Host tap Measure phone clocks and wait for eight samples. Leave automatic playback checked and delay set to None. Tap Request review at this tap. The recent camera video should arrive and play on Host.
  4. Close playback. Note Works/Problem and the displayed Tap → playback started seconds below. Camera should still be recording. On Host try Inspect host first frame, Host last frame, Previous and Next; the image and frame number should change.
  5. Measure clocks again, then request a second review. For the third, select 5 seconds: hold up one finger in Camera’s view when Host taps, then change to two. The clip should end near the one-finger moment. Close playback between requests.
  6. Stop recording and stop the session on both. Swap roles and repeat all three reviews.

If automatic playback fails, note the exact error. Try Play verified recording review; mention if you had to do this. A failed or unfinished send must never offer playback.

One reconnect check: stop the session on Host only while Camera keeps recording. Start Host again and reconnect using its new manual connection details on Camera (QR scanning requires stopping recording). Measure clocks again and request. Note whether recording continued and whether footage was available. If scanning is needed, stop recording first and report that limitation.

Second settings check: stop recording, change Camera retention/review to 60 / 10, start again and wait 15 seconds. Request and play a review on Host. It should contain roughly 10 seconds, plus any short lead-in.

Optional demonstration-video regression

Stop recording. On Camera generate and send the 20-second sample. On Host wait for a verified checksum and tap Play verified sample. Repeat after swapping roles.

3. Lock or leave the app, then return — on each phone

Recording is expected to stop when the phone is locked or you leave the app. It should work again when you return and tap Start. Stop any connection session before these checks.

  1. Start a new recording. After about 10 seconds, press the side/power button to lock the phone. Wait 10 seconds, unlock it and return to the app.
  2. Check that it is no longer recording. A stopped/interrupted message is expected; it should not claim to have kept recording while locked.
  3. Hold the phone sideways and tap Start rear camera again. Check the live view, wait 25 seconds, then extract and play a recent clip. Stop recording afterward.

One more quick check: repeat the same steps, but go to the phone’s Home screen instead of locking it. Return after 10 seconds. Recording should have stopped; starting again should restore the live view and allow a new clip.

If the app crashes, gets stuck, or will not start again, select Problem and briefly describe it below.
